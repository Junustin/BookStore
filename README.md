BookStore Web Application

This is a portfolio/learning project built to practice full-stack C# development with Blazor and Entity Framework Core.
It is a local demonstration prototype, not a production-ready commercial product.

---
* ## Core Concepts

* **EF Core: Code-First migrations, dynamic querying, entity relationships (One-to-Many, Many-to-Many).
* **Blazor: Component lifecycle management, dependency injection, parameter passing, and state handling.
* **Architecture: Separation of concerns using repository/service patterns.
 
---

* ## Key Features

* **Book Catalog:** Real-time text search using book name and author.
* **Shopping Cart:** Interactive cart management with dynamic total calculations.
* **Order Management:** Customer checkout workflow and order history tracking.
* **Admin Dashboard:** Full CRUD operations for managing inventory, categories, and stock levels.
* **Data Persistence:** Relational database mapping and migrations via EF Core.
